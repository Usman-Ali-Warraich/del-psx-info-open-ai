Maqsad aur maujooda haalat

Yeh zaati research ke liye banaya ja raha tool hai. Is ka maqsad official company reports aur announcements Google Drive mein munazzam karna hai. Cloud setup aur testing abhi jari hai.

Google data tak rasai

App Google ki ijazat ke zariye user ke chunay huay folders aur files tak rasai mangta hai. In mein company reports, download records aur portfolio ya watchlist ki company list shamil ho sakti hai.

Portfolio aur watchlist ka istemal sirf yeh tay karne ke liye hota hai ke kin companies ke documents jama karne hain. App trade execute nahin karta.

Data ka istemal

Data reports download aur save karne, duplicate files pehchanne, missing documents check karne aur download ki kamyabi ya nakami ka record rakhne ke liye istemal hota hai.

Data kahan process aur save hota hai?

Cloud workflow ke liye GitHub Actions istemal karna mansubay ka hissa hai. Run ke dauran zaroori data aur downloaded documents GitHub ke processing environment se guzar sakte hain. Mustaqil reports aur download records user ki Google Drive mein save kiye jayenge.

Google authorization credentials ko source code, public website ya public logs mein publish nahin kiya jayega. Cloud credentials ke liye GitHub Actions Secrets istemal kiye jayenge.

Sharing aur pabandiyan

Google user data ko becha nahin jata aur advertising, marketing profiles ya general-purpose AI models ki training ke liye istemal nahin kiya jata. Data sirf workflow chalane ke liye zaroori service providers, user ki wazeh ijazat, ya laazmi qanooni talab ke tehat share ho sakta hai.

Google APIs se hasil maloomat ka istemal aur doosri apps ko transfer Google API Services User Data Policy, bashamool Limited Use requirements, ke mutabiq hoga.

Data rakhna aur mitana

Reports aur records user ki Drive mein us ke control mein rehte hain. Company list se nikalne par us ka archive khud delete nahin hota. Koi routine safai sirf user ke manzoor shuda retention rules ke mutabiq ki jayegi.

User apni files aur records Google Drive se mita sakta hai. Access revoke karne se pehle save ki gayi files khud nahin mitti.

Ijazat wapas lena

User apne Google Account ki third-party connections settings se app ki rasai wapas le sakta hai aur GitHub Actions ka schedule band kar sakta hai.
